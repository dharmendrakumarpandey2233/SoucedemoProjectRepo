# SauceDemo Playwright Framework

End-to-end automation framework for https://www.saucedemo.com/ using JavaScript, Node.js, and Playwright Test.

## Setup

```powershell
npm install
npx playwright install
```

## Run

```powershell
npm test
npm run test:headed
npm run test:ui
```

This repository is being built in phases. The initial scaffold defines the project boundaries; test configuration, page objects, fixtures, scenarios, and CI are added in subsequent phases.
